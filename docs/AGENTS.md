# Regras de documentação

`PRD.md` é a fonte canônica de requisitos e progresso. Ao alterar serviço, decisão, métrica ou status, confira os links e textos relacionados.

- Só marque um requisito como `Concluído` com evidência datada no Registro de progresso, verificações relevantes e reconciliação dos critérios de aceite.
- Mantenha diagnóstico e status report como modelos até existir evidência real.
- Não inclua imagens das páginas do enunciado nem dados sensíveis.
- Em divergência entre PRD e guias de serviço, registre a divergência e resolva antes de implementar.
