# DEV-01 — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** preparar contratos por jornada e demonstrar uma consulta frontend → API → fonte sintética substituível pela Gold.

**Architecture:** contratos Pydantic e serviços analíticos dependem de uma interface de leitura injetável. A implementação inicial usa dados determinísticos em memória; o frontend valida a resposta e oferece uma rota somente de desenvolvimento. Ordens operacionais e serviço de IA existentes são preservados.

**Tech Stack:** Python 3.12, FastAPI, Pydantic, pytest; React, TypeScript, Vite, TanStack Query, Vitest/Testing Library e Tailwind existentes.

**Spec:** [desenho DEV-01](../design/2026-10-20-dev01-design.md), aprovado em conversa; execução com dois subagentes GPT-6 Luna/high explicitamente solicitada.

## Restrições globais

- Branch `dev01`, base `origin/develop` em `d59f7f2`.
- Fonte sintética explícita; nenhum dado real, segredo ou esquema Gold presumido.
- Sem novas dependências de produto, migração ou alteração de banco nesta entrega.
- API versionada e metadados do desenho são o acordo entre os dois implementadores.
- Controlador mantém documentação de produto e revisa os dois trabalhos; agentes não fazem commit, push ou merge.
- A revisão final considera padrões do repositório e checklist/especificação separadamente, feita pelo controlador conforme pedido da pessoa usuária.

## Foco de revisão

1. Ausência ou nulidade não vira zero: HTTP e interface distinguem os quatro estados.
2. Filtro aplicado não pode apenas aparecer no metadado: conferir resultado com controles independentes.
3. Página/ordenação não pode perder ou repetir registros; limitar tamanho e desempatar de forma determinística.
4. Resposta malformada ou atrasada não aparece como dado válido do recorte novo.
5. Modo sintético não é ativado silenciosamente e a rota de diagnóstico não existe no build de produção.
