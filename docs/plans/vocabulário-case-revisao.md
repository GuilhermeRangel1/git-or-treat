# Vocabulário do case para revisão

Base: trechos fornecidos na conversa, [PRD](../PRD.md) e [levantamento do case](../gold-coverage-v0.md). A extração direta do PDF ficou indisponível. “Apagão” e “queda de luz” são variantes sugeridas para revisão.

Marque **ok** ou escreva a definição que espera. Os períodos já combinados usam junho de 2026 como referência e aparecem na resposta.

| Termo ou pergunta | Leitura proposta | Sua revisão |
| --- | --- | --- |
| Volume residencial, perda de volume | Consumo medido em kWh. Ordenar os bairros pela perda absoluta e mostrar também a variação percentual. | |
| Volume de energia faturada | Energia que entrou na fatura, em kWh. Confirmar se consumo medido pode aparecer como aproximação explicitamente rotulada quando faltar a medida faturada. | |
| Conta de luz | Pode significar valor faturado, valor pago ou consumo. Sem pista suficiente, perguntar qual. | |
| Faturamento, receita, arrecadação | Faturamento e receita faturada correspondem a valor da fatura. Arrecadação corresponde ao que foi pago. | |
| Cresceu em Jaboatão | Mostrar diferença em reais e percentual. Confirmar se, sem datas, compara os últimos 12 meses com os 12 anteriores. | |
| Falta de luz, queda de luz, apagão | Interpretar como interrupção. Para “apagão”, confirmar se qualquer interrupção conta ou se exige um evento de grande alcance. | |
| Onde mais faltou luz? | Perguntar se o ranking é por quantidade de eventos, duração ou unidades afetadas quando a frase não der pista. | |
| Chamados, reclamações, atendimento | Chamado é protocolo. Reclamação pressupõe categoria específica. Atendimento também pode significar satisfação ou tempo de resolução. | |
| Solar, GD, queda de consumo acima de 30% | Usar jan–jun/2026 como recorte padrão. Confirmar jan–jun/2025 como base e se “solar” pode usar a marcação de GD quando a tecnologia não estiver confirmada. | |
| Tarifa, preço médio do kWh | Tarifa homologada e preço médio observado são medidas diferentes. Confirmar a esperada quando o pedido for ambíguo. | |
