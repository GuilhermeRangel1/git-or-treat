# Contexto de domínio para skills

Produto: plataforma interna Grid 360 da V-Energy. Entidade central de atendimento: unidade consumidora (UC), que não é o mesmo que cliente. Competência é o mês de referência; data de pagamento pode ser posterior. Receita faturada, recebimento, consumo apurado e energia faturada são métricas diferentes. Alimentador é circuito de rede; DEC/FEC do case são indicadores internos simplificados. Geração distribuída pode reduzir energia faturada. Suspeita de perda não técnica não é fraude confirmada.

Vocabulário completo: [PRD §3](../PRD.md#3-glossário-de-domínio). Métricas e campos reais: [dicionário](../dicionario_gold.md), a preencher após inspeção do dataset. Decisões em aberto: PRD §8 e §12.
