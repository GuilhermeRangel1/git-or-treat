O rastreador inicial é **local no repositório**. Use `.scratch/<tema>/issues/<NN>-<slug>.md` para tickets criados por `to-tickets`, com bloqueios em texto e ID(s) do PRD. `.scratch/` é espaço de planejamento e não substitui `docs/PRD.md`; tickets concluídos só alteram o PRD após a evidência de qualidade. Se o time escolher GitHub Issues ou outro rastreador depois, atualize este arquivo por decisão registrada. Rótulo local sugerido: `ready-for-agent`; outras categorias podem ser acrescentadas no próprio ticket.
