# Decisões arquiteturais (ADR)

Registre aqui escolhas que alterem contratos, métricas, banco, framework de IA, privacidade ou limites da solução. Cada ADR deve conter **data, estado, contexto, opções consideradas, decisão, consequências e IDs do PRD afetados**. Atualize o PRD e os guias relacionados na mesma mudança. Nenhuma decisão arquitetural está aprovada nesta etapa.
