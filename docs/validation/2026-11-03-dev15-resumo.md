## Reproduzir as verificações versionadas

É necessário preparar ambiente privado com dependências do Backend/Frontend, banco migrado carregado com o pacote real, configuração `backend/.env` e contas autorizadas. Não versionar pacote Gold, arquivos de ambiente ou credenciais. A API deve usar o mesmo banco/publicação dos validadores. Os resultados vão para `work/`, ignorado pelo Git.

Em `backend/`, iniciar a API atual:

```powershell
$env:BACKEND_CORS_ORIGINS='["http://127.0.0.1:5173","http://127.0.0.1:5185"]'
.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8015 --no-access-log
```

Da raiz, com diretório de saída existente e credenciais privadas no formato `<perfil> username: ...` / `<perfil> password: ...`:

```powershell

backend/.venv/Scripts/python.exe scripts/validate-dev15-web.py --credentials work/local-auth/credentials.txt --api-base http://127.0.0.1:8015 --output work/dev15-validation/http.json --reconcile
backend/.venv/Scripts/python.exe scripts/validate-dev15-data.py --credentials work/local-auth/credentials.txt --output work/dev15-validation/data.json
```
