# Regras de frontend

Leia `../docs/services/frontend.md` e os IDs WEB relevantes de `../docs/PRD.md`. O portal usa React + TypeScript com Vite e consome a API FastAPI.

- Mostre unidade, período, filtros, atualização, estado vazio e erro em cada métrica.
- Teste as jornadas de diretoria, comercial, atendimento, perdas e operação.
- Consulte a skill `vercel-react-best-practices` para performance; adapte as recomendações ao Vite do projeto.
- Use Figma apenas quando houver referência de arquivo ou frame disponível.
- Execute formatação, lint, tipos, testes e build disponíveis antes de marcar requisitos como concluídos.
